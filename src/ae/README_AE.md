# 打螺丝 · After Effects 工程导出说明

## 使用步骤
1. 网页工具中点「▶ 自动通关」（自动开始记录），或在面板「导出 AE 工程」里点「● 开始记录」后手动游玩；完成后点「■ 停止并导出」/「⬇ 导出 ZIP」，得到 `screw_ae_export_*.zip`。开启「录制视频时同步记录，停止录制后自动导出」时，停止视频录制会自动导出。
2. 解压到任意文件夹（保持 `build_ae_project.jsx`、`timeline.json`、`assets/`、`audio/` 在同一目录）。
3. After Effects（CC 2018 及以上）→ 文件 → 脚本 → 运行脚本文件… 选择 `build_ae_project.jsx`。脚本按自身位置查找素材，不需要改路径。
4. 脚本新建工程、导入素材、建立「主合成_打螺丝」（尺寸=「AE 合成尺寸」，帧率=「AE 合成帧率」），完成后会弹出统计（图层数 / 关键帧数 / 标记数），并询问是否**另存为 .aep**（「脚本跑完后提示另存为 .aep」）。

> 如果提示“脚本没有写入文件的权限”：在 编辑 > 首选项 > 脚本和表达式 勾选 **允许脚本写入文件和访问网络**。只影响最后一步保存 .aep。

## 文件
| 路径 | 内容 |
|---|---|
| `build_ae_project.jsx` | 构建脚本 |
| `timeline.json` | 时间轴（meta / folders / assets / comps / mainComp） |
| `assets/` | PNG 素材（英文文件名，AE 中显示名随「图层命名」中文/English） |
| `audio/` | `mix.wav` 混合音轨，`sfx_*.wav` 每种音效单独一份 |
| `README_AE.md` | 本说明 |

## 图层结构（从下到上）
- 背景、手形底板
- 孔 N：被板盖住的孔在覆盖它的最后一块板开始下落时出现（入点 + 标记「露出」）
- 板块 N 投影 / 板块 N：静止的板（贴图含板上自己的孔），出点 = 开始下落时刻
- 螺丝 N @孔M 螺帽 / 十字槽：螺丝静止在某孔的时段（十字槽角度 = 当时的旋转角）
- 板块 N 下落：重力下落（位置关键帧逐帧烘焙/精简，旋转、可选淡出），画在静止螺丝之上
- 螺丝 N 移动#K 投影 / 螺杆 / 螺帽 / 十字槽：拧出抬起（缩放、旋转）、悬停、沿弧线飞行、拧入（旋转、缩放回落）、回弹；投影不透明度随抬起高度，螺杆 Y 缩放 = 抬起高度（露出螺杆）
- 免责声明（若开启）、结束页（若开启，不透明度关键帧）
- 手指：上传的 PNG（结束页出现后按「结束页显示手指」隐藏），锚点 = 指尖，位置 + 按下缩放，显示/隐藏为定格关键帧
- 混合音轨 / 音效_逐事件（预合成，每个音效一层放在发生时刻）；与麻将工具一致两者默认都开，逐事件音效叠在一起时可能略响，需要和网页一致的声音请只保留 `mix.wav`（或选「仅混合音轨」）。
- 主合成标记：每个音效事件一个（拧出棘轮 / 拧入棘轮 / 拧紧到位 / 板掉落）。

## 说明
- 图层命名可选中文/English（「图层命名」），与麻将工具同一规范（见工具仓库 ref/TOOLKIT_STANDARD.md）。
- 板的掉落时刻已包含「螺丝阻挡探测」：板只有在没有任何贯穿螺丝时才掉落，导出的时间与网页一致。
- 关键帧默认「精简」（线性插值误差 ≤0.25px 内删减），可在设置里改为「逐帧烘焙」。
- 螺杆螺纹是静态贴图（网页里螺纹随旋转滚动），点击波纹、调试叠加不导出。
- 若在记录后修改了画布/外观参数，请重新开始一局再导出。
