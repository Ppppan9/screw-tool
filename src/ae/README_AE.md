# 打螺丝 · After Effects 工程导出说明

## 使用步骤
1. 网页工具中点「▶ 自动通关」（或手动游玩），完成后点「导出 AE 工程」，得到 `screw_ae_export_*.zip`。
2. 解压到任意文件夹（保持 `build_ae_project.jsx`、`timeline.json`、`assets/`、`audio/` 在同一目录）。
3. After Effects（CC 2018 及以上）→ 文件 → 脚本 → 运行脚本文件… 选择 `build_ae_project.jsx`。脚本按自身位置查找素材，不需要改路径。
4. 脚本新建工程、导入素材、建立「主合成_打螺丝」（720×1280，帧率=导出设置），完成后可选择另存为 .aep。

## 图层结构（从下到上）
- 背景、手形底板
- 孔 N：被板盖住的孔在覆盖它的最后一块板开始下落时出现（入点 + 标记「露出」）
- 板块 N 投影 / 板块 N：静止的板（贴图含板上自己的孔），出点 = 开始下落时刻
- 螺丝 N @孔M 螺帽 / 十字槽：螺丝静止在某孔的时段（十字槽角度 = 当时的旋转角）
- 板块 N 下落：重力下落（位置关键帧逐帧烘焙/精简，旋转、可选淡出），画在静止螺丝之上
- 螺丝 N 移动#K 投影 / 螺杆 / 螺帽 / 十字槽：拧出抬起（缩放、旋转）、悬停、沿弧线飞行、拧入（旋转、缩放回落）、回弹；投影不透明度随抬起高度，螺杆 Y 缩放 = 抬起高度（露出螺杆）
- 免责声明文字（若开启）、结束卡（若开启，不透明度关键帧）
- 手指/触控笔：上传的 PNG，锚点 = 指尖，位置 + 按下缩放，显示/隐藏为定格关键帧
- 音效_逐事件（预合成，每个音效一层放在发生时刻）+ 混合音轨（默认关闭音频开关，二选一）

## 说明
- 板的掉落时刻已包含「螺丝阻挡探测」：板只有在没有任何贯穿螺丝时才掉落，导出的时间与网页一致。
- 关键帧默认「精简」（线性插值误差 ≤0.25px 内删减），可在设置里改为「逐帧烘焙」。
- 螺杆螺纹是静态贴图（网页里螺纹随旋转滚动），点击波纹、调试叠加不导出。
- 若在记录后修改了画布/外观参数，请重新开始一局再导出。
